# Oniflow Help

## Recommended Settings

- Anime: use the Anime profile.
- Human footage: use the Human profile.
- Most RTX GPUs: use Normal quality and mixed precision.
- 4K video: keep 4K Processing Mode set to Auto.
- Low VRAM: use Fast quality and Memory Saver.

## Common Errors

### GPU VRAM is insufficient

Use Fast quality, reduce FPS Multiplier, or select Memory Saver.

### Unsupported encoder

Select H.264 or update the NVIDIA graphics driver.

### Output drive is full

Select another output directory with more free space.

## Process Controls

- Pause temporarily suspends Oniflow and its child processes.
- Resume continues the same process.
- Stop cancels the current item.

## Offline License Preparation

Oniflow uses a signed offline license bound to one Windows computer.

1. Open Oniflow on the target computer.
2. Copy the Device ID shown by Oniflow.
3. Send the Device ID to the Oniflow owner.
4. Import the license file created specifically for that computer.

The license works without an internet connection. A license made for one computer cannot activate another computer.

Payment, subscription, redeem-code, and daily-clip restrictions remain disabled.
