# Oniflow Privacy Policy

Oniflow processes videos locally on the user's computer.

The current version does not upload videos, process logs, or account information. Links to TikTok, Instagram, and email open external applications or websites selected by the user.

Future update checking or telemetry features must remain disabled until this policy is updated and the user provides clear consent.

The current subscription and access-code interface is a local visual preview. It does not validate codes, process payments, create accounts, or transmit subscription data.
